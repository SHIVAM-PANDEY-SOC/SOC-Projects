# 🛡️ SOC Projects

A collection of hands-on Security Operations Center (SOC) and Blue Team projects focused on log analysis, threat detection, malware analysis, endpoint security, and incident response.

These labs were built in isolated environments using industry-standard tools to simulate real-world SOC workflows and strengthen practical cybersecurity skills.

| Project | Description | Status |

| 🐧 Linux Security Monitoring | Linux log monitoring, event analysis, and security investigations. | ✅ Completed |
